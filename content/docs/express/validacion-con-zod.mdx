## La idea

Todo lo que llega de fuera (cuerpo, query string, parámetros, variables de entorno, archivos) es **no confiable**. <Term slug="zod">Zod</Term> te deja describir la forma esperada una vez y obtener validación, mensajes de error y datos limpios:

```js
import { z } from 'zod';

const userSchema = z.object({
  name: z.string().trim().min(2),
  age: z.coerce.number().int().min(18),       // '42' (texto de la query) → 42
  role: z.enum(['admin', 'editor']).default('editor'),
});

userSchema.parse({ name: '  Ana ', age: '42' });
// → { name: 'Ana', age: 42, role: 'editor' }

const result = userSchema.safeParse({ name: 'A', age: 'x' });
result.success;         // false
result.error.issues;    // [{ path: ['name'], message: … }, { path: ['age'], message: … }]
```

- `parse` lanza un error si no es válido; `safeParse` devuelve `{ success, data | error }`.
- `z.coerce.*` convierte texto (query strings, variables de entorno) al tipo esperado.
- `.transform()` convierte el valor tras validarlo; `.refine()` añade reglas propias.
- **Los campos que no están en el schema se eliminan**: el cliente no puede colar `id` ni `isAdmin`.

## Mensajes en español

Zod 4 incluye traducciones. Actívalas una vez al arrancar:

```js
z.config(z.locales.es());
// "Demasiado pequeño: se esperaba que texto tuviera >=2 caracteres"
```

## Validar en el handler

Con un pequeño ayudante que convierte el fallo en un `ValidationError` (400), cada ruta empieza con una línea de validación y trabaja con datos ya seguros.

## Errores comunes

- **Validar solo el cuerpo**: `req.params.id` y `req.query.limit` también llegan del cliente.
- **Valores por defecto en schemas de actualización**: con `.partial()`, Zod 4 sigue aplicando los `.default()`, y un `PATCH` que solo cambia el importe pondría la descripción a `''`. Define el schema de actualización sin defaults.
- **Validar dentro del servicio y también en la ruta**: valida en la frontera (la ruta) y pasa al servicio datos ya tipados.

Cada ruta valida su entrada en la primera línea. Por ejemplo:

```js title="src/expenses/expenses.routes.js"
import { parse } from '../lib/validation.js';
import { createExpenseSchema, idSchema } from './expenses.schema.js';

router.post('/', async (req, res) => {
  const data = parse(createExpenseSchema, req.body);
  // data.amount ya es un entero en céntimos; data.category, una categoría válida
});

router.get('/:id', async (req, res) => {
  const { id } = parse(idSchema, req.params); // '7' → 7; 'abc' → 400
});
```
