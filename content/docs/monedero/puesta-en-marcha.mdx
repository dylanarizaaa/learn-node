## Arrancar en un minuto

La carpeta `proyecto/` del repositorio contiene Monedero completo: el resultado de los 10 hitos.

```bash
cd proyecto
npm install
cp .env.example .env          # y pon un JWT_SECRET de 32 caracteres o más
npm run dev                   # http://localhost:3000
```

```bash
npm test                      # 37 tests de unidad e integración
```

Requiere **Node 22.18 o superior** (recomendado Node 26 LTS). En Node 22 verás un aviso `ExperimentalWarning` de SQLite: es esperado.

## Scripts

| Script | Qué hace | Hito |
| --- | --- | --- |
| `npm run dev` | Servidor con recarga al guardar y logs legibles | 4, 8 |
| `npm start` | Servidor en modo normal | 4 |
| `npm run start:cluster` | Un worker por núcleo | 9 |
| `npm run start:secure` | Con el modelo de permisos de Node | 9 |
| `npm run cli -- <comando>` | La CLI (`add`, `list`, `summary`, `import`, `export`) | 2, 3 |
| `npm run migrate` | Aplica las migraciones sin arrancar el servidor | 6 |
| `npm test` | Tests con `node:test` | 8 |
| `npm run test:coverage` | Tests con informe de cobertura | 8 |
| `npm run typecheck` | Comprobación de tipos con JSDoc | 8 |
| `npm run audit:prod` | Vulnerabilidades en dependencias de producción | 7 |

## Estructura

```tree title="proyecto/"
  monedero.js # CLI (hitos 2-3)

  app.js # composición de Express (hito 5)
  config.js # entorno validado con Zod (hito 10)
  health.js # /health y /ready (hito 9)
  domain/expenses.js # reglas puras (hito 1)
  lib/ # dinero, errores, validación, logs, contexto
  db/ # conexión, transacciones y migraciones (hito 6)
  expenses/ # schema → rutas → servicio → repositorio
  users/ # contraseñas, JWT, registro y login (hito 7)

Dockerfile # imagen de producción (hito 10)
```

## Un paseo por la API

```bash
# 1. Crear una cuenta y guardar el token
TOKEN=$(curl -s -X POST localhost:3000/api/auth/register \
  -H 'content-type: application/json' \
  -d '{"email":"ana@example.com","password":"contraseña-segura"}' | node -e "process.stdin.on('data', (d) => console.log(JSON.parse(d).token))")

# 2. Registrar gastos
curl -X POST localhost:3000/api/expenses -H "Authorization: Bearer $TOKEN" \
  -H 'content-type: application/json' -d '{"amount":"12,50","category":"comida","description":"Almuerzo"}'

# 3. Escuchar eventos en otra terminal
curl -N localhost:3000/api/events -H "Authorization: Bearer $TOKEN"

# 4. Resumen del mes e informe del año
curl localhost:3000/api/expenses/summary -H "Authorization: Bearer $TOKEN"
curl localhost:3000/api/reports/2026 -H "Authorization: Bearer $TOKEN"
```

Y con la CLI, sobre la misma base de datos:

```bash
npm run cli -- summary --user ana@example.com
```
